# How to add an environment variable to the Container App

Two cases, depending on whether the value is a secret.

## Plain (non-secret) value

Add an `env` block in `modules/container_app/main.tf`, inside the `container` block:

```hcl
env {
  name  = "MY_NEW_VAR"
  value = "some-value"
}
```

If the value should come from the root module rather than be hardcoded, add a variable
in `modules/container_app/variables.tf`, wire it through from the root `main.tf` module
call, and reference it as `value = var.my_new_var`.

## Secret value

1. Add the key to the `secrets` map you pass via `TF_VAR_secrets` (see
   [rotate a secret](rotate-a-secret-in-key-vault.md)) — this gets it into Key Vault.
2. Add a matching `env` block in `modules/container_app/main.tf`:
   ```hcl
   env {
     name        = "MY_NEW_SECRET"
     secret_name = "my-new-secret"
   }
   ```
   `secret_name` must match a key in the `secret` block generated by the
   `dynamic "secret"` loop, which in turn comes from `var.kv_secret_ids` — so as long as
   the key exists in `secrets`, it flows through automatically; you only need to add the
   `env` block that references it.

Re-run `terraform apply` after either change.
